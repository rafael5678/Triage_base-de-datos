# Guía de Conexión con DBeaver

Pasos para gestionar visualmente la base de datos:
1. Crear nueva conexión tipo **PostgreSQL**.
2. Host: `localhost` o el host de Supabase / Render.
3. Database: `hospital_triage`.
4. Habilitar SSL en `require` para conexiones remotas.
5. Probar conexión y explorar las tablas del esquema `public`.
